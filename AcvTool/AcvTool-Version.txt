------------------------------------------------------------------------
1. APP DESCRIPTION
------------------------------------------------------------------------
Acv Tool là phần mềm giải nén/nén file data *.acv của game Audition PC.
Hỗ trợ nghiên cứu, chỉnh sửa và quản lý dữ liệu của game.
Các tính năng cốt lõi:
- Giải nén/Nén lại file .acv
- Tự động nhận diện thế hệ file .acv
- Tự động xử lý hàng loạt
